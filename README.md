# MoonBerry
Personalised, illustrated bedtime stories where your child is the hero, read aloud.

Static site (GitHub Pages). Accounts, parental consent, child profiles, the story library, favourites, and listen history are stored in Supabase (Auth, Postgres row-level security, and Storage). Studio narration MP3s stay in this repository. Visitors can still try a free 5-minute story before creating an account.
